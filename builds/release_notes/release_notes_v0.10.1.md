## 本版修复与改进

- **树操作不再触发整树重载**：新建 / 重命名 / 删除 / 移动计划与文件夹后，树原地更新——展开状态保持、无闪烁（此前操作回声会引发整树重新加载）；外部文件变更也只更新受影响的位置
- **树侧边栏可拖拽调宽**：拖动树右缘调整宽度（180–520px），宽度自动记住（借鉴 VS Code 行为）
- **注释渲染器扩展**：支持 HTML 注释剥除（不再字面泄漏）、引用块、分隔线、表格渲染
