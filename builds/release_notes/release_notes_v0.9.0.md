# v0.9.0

溯源 Trace 首个公测版（Beta，2026-09-09 构建）。

- 平台：Windows x64（NSIS 安装包）
- 构建状态：beta（公测版）
- 数据：.plan 明文存储于计划库根目录，可整库拷贝备份；数据不出设备

## 版本功能（0.1-0.9 里程碑概述）

- 树形计划：计划/文件夹、拖拽归类、树动效卡牌摞（发牌/收牌/折叠变号）、展开动画
- 组件卡：注释（Markdown 双态渲染）/ 任务清单（足迹三态）/ 任务详情 / 单计划（截止日期）/ 多计划 / 今日心情（分数轮带+冷暖色阶）/ 标题（字号滑杆）/ 自定义（Markdown+预设快照）
- 追溯定位：全文检索（计划/注释/组件）+ 回溯脉冲定位
- 导入导出：.plan zip 打包 / Markdown 旧计划迁移（npm run migrate:md）
- 本地优先：无边框自绘窗口、VS Code 式菜单、设置弹窗（界面语言中/英、树展开方向、心情分数动画）、状态栏
- 本轮（0.9.0）：禁止瞬切整顿——hover/出现/状态切换全部平滑过渡（删除钮 overlay 化、交互基线 --t-ui、逾期标/搜索浮层入场动画、prefers-reduced-motion 覆盖）
