# v0.15.0

溯源 Trace 公测版 Beta 5（2026-09-24 发布）——回忆、Muya 注释与前端地基。

- 平台：Windows x64（NSIS 安装包）
- 数据：计划库仍为本地明文 `.plan` 文件，可整库拷贝备份；本版不改变计划文件格式
- 版本跨度：相对上次 v0.12.0，本次有三个独立的大批次，因此跨到 v0.15.0；仍为公测版

## 本版新增

- 回忆视图：那年今日、里程碑、随机回忆，支持当日内容预览及回到树中原计划。
- 注释改用真正的 Muya 编辑器：在同一编辑面实时排版 Markdown，支持自动补全、代码块语言选择及 Mermaid、Vega、PlantUML 等图表。实时渲染和自动换行默认开启；PlantUML Server 不配置时保持离线。
- 更统一的操作体验：删除确认和 5 秒撤销，三视图响应式应用壳，主题对比度、键盘焦点与减弱动效改进。

## 修复与性能

- 注释编辑时点击外部、移走焦点或移动卡片会回到阅读态；`# 123` 等标题在阅读态显示为标题，而不是源码。
- 回忆视图顶栏、高度、随机抽取范围和文案问题修复。
- 大树节点局部订阅、搜索结果分页显示；组件编辑和 Muya/页面资源按需加载。
- 阅读态注释的外部链接仅允许安全的 HTTP(S) 地址。

## 已知限制

- 首次打开注释编辑器需加载 Muya，加载时长随设备而异；此前开发模式中报告的首次加载超过 1 秒/可能重载仍在跟踪，不在本版标记为已修复。
- Muya 的 IME、剪贴板、图表浮层等完整 Electron 人工体验仍需继续验收；本版已通过自动测试和构建，不能等同上述人工验收。
- 安装包未使用商业代码签名证书，Windows SmartScreen 可能要求用户确认。
