# v1.1.0 — 溯源 Trace：可配置计划工作流

相较 v1.0.0，本版增加按目录匹配的计划工作流预设，并改进设置页与小沅计划操作。

## 新增与改进

- 计划工作流可配置匹配目录、目标文件夹、命名规则和内容模板。新建时先展示可修改预览，确认后才写入计划文件。
- 周日联动可一次安排一份周计划与最多七份日计划，为各日分配任务；下一周可显式交接上一周未完成任务。相关计划 ID 在导入导出发生冲突时同步重映射。
- 工作流设置默认展示预设列表，显示名称、匹配范围和生成项信息；选择后再编辑。当前名称、未保存状态与保存入口固定在编辑页顶部，新建和复制自动生成可区分名称。
- 不常见设置提供可展开说明，覆盖功能、设置目的、适用对象和设置效果。
- 小沅的工作流操作沿用目标授权、预览和确认机制；本版还包含计划操作及请求诊断的增量改进。
- Windows 原子保存遇到短时拒绝时，有限退避重试增加一次机会；若仍失败，编辑态保留内容供再次保存。

## 兼容性与已知边界

- 计划仍以本地 Markdown/JSON 文件存储。升级前建议备份个人计划库。
- 工作流曾在隔离 Electron 环境创建单计划，并通过生产 IPC 验证跨年周日批次。真实个人计划库中的批量创建、真实模型调用、全部原生界面操作和 NSIS 安装/卸载尚未完成用户侧验收。
- 安装包未数字签名，Windows 可能显示未知发布者提示。
- 原子覆盖已有 `plan.json` 的间歇性 Windows `EPERM` 已在合成测试库捕获。ProcMon 同一路径上可见 `MsMpEng.exe` 的文件映射事件，但发生在首次重命名拒绝之后，无法证明 Defender 是原因。有限重试覆盖本轮捕获的约 785 毫秒拒绝窗口；更久的拒绝仍可能导致保存失败，根因未归因。
