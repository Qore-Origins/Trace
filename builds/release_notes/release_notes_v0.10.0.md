# v0.10.0

溯源 Trace 公测版 Beta 2（2026-09-10 构建）——日记深化。

- 平台：Windows x64（NSIS 安装包）
- 构建状态：beta（公测版 Beta 2）
- 数据：.plan 明文存储于计划库根目录，可整库拷贝备份；数据不出设备

## 本版新增

- **日记深化（四位一体）**
  - 自动日计划：计划库内「日记」根（`Diary/`）自动维护——每天首次打开日记即生成当日页，预置「标题 / 今日心情 / 今日小结」模板，只建不补、绝不覆盖你的改动
  - 日历回顾：顶栏「日记」入口——月历热力（每天的心情色彩与分数、组件数）、点日期即预览当日内容、右侧当月时间线
  - 统计趋势：本月均分 / 打卡天数 / 记录条数与心情趋势折线（无记录的日子不按 0 计）
  - 记录顺滑：「在树中打开」从日记直达计划树定位；树内「日记」根蓝标区分
- **树操作语义修正**：新建子项（悬停快捷钮与右键菜单）仅出现在文件夹与库根——计划不再显示

## 修复

- 日记视图下顶栏搜索 / 新建计划 / 设置恢复可用；切换计划库后日记数据即时刷新
- 计划创建产生的文件夹事件不再误触发「计划库在应用外被修改」提示
- 单计划卡截止日期左缘对齐；心情日期清空回退为今天
