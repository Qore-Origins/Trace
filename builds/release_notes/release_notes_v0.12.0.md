# v0.12.0

溯源 Trace 公测版 Beta 4（2026-09-12 发布）——深色主题与导出为。

- 平台：Windows x64（NSIS 安装包）
- 构建状态：beta（公测版 Beta 4）
- 数据：.plan 明文存储于计划库根目录，可整库拷贝备份；数据不出设备

## 本版新增

- **深色主题**：设置 → 界面主题可选 亮色 / 暗色 / 跟随系统——全界面（工作台/日记/搜索浮层/弹窗/菜单）与代码高亮、滚动条、原生日历弹层统一暗色；亮暗切换为整页丝滑渐变（可自定义时长）
- **导出为（PDF / 图片）**：文件菜单新增「导出为 PDF…」「导出为图片…」——把当前计划渲染为 A4 文档（文字可选中可搜索）或整页图片，随当前主题取色

## 修复与改进

- 计划树排序：混用 `-`/`_` 分隔符的命名现在按日期直觉序排列（此前 `Daily_Plan_x` 组会整体跳到 `Daily_Plan-x` 组前面）
- 任务行日期的日历弹层、滚动条等原生控件随主题配色
- 新建/重命名重名时弹窗提示具体原因（对话框保持开启可直接改名）
- 删除计划/文件夹时平滑收合动画（右键与 Delete 键均生效）
- 拖拽排序时被拖卡片不再变形
- 多项内部质量改进（日历日期真伪校验、数据守卫加固等）
