# 小沅计划操作与恢复原型

Task 6 独立静态 Demo。直接用浏览器打开同目录 `index.html` 即可，无需构建或依赖。

默认是融合工作台：桌面双栏左侧当前批次对话、右侧预检/执行/恢复任务流。输入框在左栏底部常驻；消息和工作内容各自滚动。每个批次只展示自己的来源消息及其回复，续轮也留在所属批次；其他批次不会串入。约 960px 以下可切换“任务交流 / 工作内容”，同一个输入框仍固定可见，切换不会丢失草稿或输入状态。短视口下右侧工作内容改为整栏纵向滚动，阶段导航和必要操作可滚动到达，composer 仍占独立可见行，不覆盖正文。尝试流水与逐项回执按需展开，不再以整页编年事件呈现。

## 体验路径

1. 新消息的 `@` 目标默认留空：普通对话和新建内容无需 `@`；如需操作已有计划/文件夹，可添加多个目标。空目标消息仍可预览和发送，但所有已有对象工具都显示越界并阻止执行，小沅会在本地模拟澄清“需要操作已有计划时请用 @ 指定目标”。`@` 只限定本地读取范围，不自动附加正文。草稿目标与已确认消息的冻结授权分开展示，修改草稿不会扩大旧批次授权。
2. 点击“预览本次外发”，核对精确目标、历史、偏好、默认关闭的本地读取摘要及完整外发内容。取消后可改目标重新预览；确认后该消息的目标授权冻结。继续操作的预览会冻结完整历史回执，并明确仅处理尚未执行项。
3. “预检”按需展开前后差异与引用影响；“执行”勾选写入授权后串行模拟操作。第二项必定失败，后续项停止。
4. “恢复”中重试只针对失败项，继续只针对 pending 项，成功项不重放。批准和逐项结果追加到不可变尝试历史。外发预览或本地写入确认任一取消都不产生操作副作用。
5. 回收站仅包含计划和文件夹。同名恢复须改名且不覆盖；永久清除逐项确认。回执显示本次 Demo 模拟的恢复名称和位置。
6. 切换“待核验”场景：突出显示可能已发生但尚未核实的状态，禁用重试、继续和撤销，并要求人工核对。

## 数据与交互边界

- 仅使用合成数据、内存状态和定时器；无网络、真实计划库、文件系统、Trace IPC、服务商、模型或凭据。刷新/重置会丢弃模拟变更。
- 支持亮/暗主题与中文/英文。消息 `Enter` 换行，`Ctrl + Enter` 打开外发预览；输入法组合期间不触发提交。弹窗使用原生 `<dialog>`，Escape 可取消。
- 桌面两栏与右侧阶段内容、左侧消息分别独立滚动。窄屏切换工作面时输入框始终是同一 DOM 节点，不复制或卸载；定时器刷新保留草稿、焦点、选区、滚动和展开状态。
- 不自动滚底、FLIP 或增加切页动效，遵循 `prefers-reduced-motion`。

这是体验原型，不代表生产安全边界。外发确认窗口、路径/版本复核、引用更新、审计持久化、崩溃恢复与回收站实际存储仍由生产实现负责。尚未完成真实 Electron、IME、读屏、真机或不同 DPI 的视觉验收；用户确认体验后才进入 Task 7 正式集成。
