# 注释失焦阅读态未渲染 Markdown 图表

状态：已修复并完成真实 Electron 失焦态验证；尚未合入主分支或发布。

## 现象

注释聚焦编辑后失焦，围栏中的 Mermaid 图仍显示原始源码；相同的静态阅读态也影响 Vega-Lite、PlantUML、Flowchart、Sequence 等 Muya 支持的图表语言。

## 根因

活动态使用 Muya 解析 Markdown 图表；非活动态 `NoteMarkdown` 将所有围栏一律输出为 `<pre><code>`，代码块之外的标题/链接等语法可以渲染，但图表 fence 没有连接 Muya 图表渲染器。

## 修复

- 静态 Markdown 解析器只对 Muya 支持的五种图表 fence 调用对应本地图表 renderer，其余语言仍按普通代码块渲染。
- 复用 vendored Muya 的惰性图表加载器，避免另建一套渲染管线。
- Mermaid/Vega-Lite/Flowchart/Sequence 本地生成 SVG；PlantUML Server 默认未设置时明确提示“源码未发送到网络”，不尝试公共 Server。
- 失焦静态卡片继续沿用现有安全 HTTP(S) 外链处理；图表异步清理和错误状态限定在该图表卡片内。
