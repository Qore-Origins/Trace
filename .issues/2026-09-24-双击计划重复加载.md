# 双击计划触发重复加载与内容闪烁

状态：已修复并经用户在当前 Electron 应用复验；随 v0.15.1 发布

## 现象

在计划树中双击切换到另一计划时，内容区快速连续出现两次“载入中…”和计划内容，视觉上像页面闪烁。

## 根因

计划树行使用 `onClick` 打开计划。双击会产生两次 click 事件，分别调用 `usePlanStore.open(path)`。原实现每次都清空当前文档并发起一次 `storage:readPlan`，因此同一路径会经历两轮加载状态。

## 修复

- 相同路径存在进行中的读取时复用该请求。
- 当前路径已加载完成时，普通重复打开直接返回，不再清空文档或读取。
- 显式刷新和 `trace:plan-changed` 外部变更回读使用强制刷新参数，维持原有刷新语义。
- 关闭计划时清理活动读取标记；过期 IPC 结果仍由 session revision 丢弃。

## 回归验证

- 修复前：`npx vitest run test/plan-editing.spec.ts` 中新增用例失败，双击同一路径触发 2 次 IPC 读取。
- 修复后：同一用例验证并发重复打开只读一次、加载完成后的重复点击不重载、强制刷新仍发起新读取。
- 全量：`npm run typecheck` 通过；`npm run test` 28 文件、249/249；`npm run build` 成功。

## 后续

已纳入 v0.15.1；用户在 Electron 应用双击计划树项目确认加载占位和内容不再重复闪现。
