# 注释阅读态外链点击无效

状态：已修复并通过主进程窗口策略单测；尚未合入主分支或发布。

## 现象

注释退出编辑后，Markdown 链接显示为链接样式，但点击后没有打开系统浏览器。

## 根因

阅读态通过 `window.open(url, '_blank')` 请求新窗口，而主进程 `setWindowOpenHandler` 对所有请求一律 deny，未把受信协议转交给系统浏览器。

## 修复

- 新建 `createExternalLinkWindowHandler`：始终拒绝 Electron 子窗口，只允许无凭据的 HTTP(S) URL 调用 `shell.openExternal`；其他协议拒绝。
- 外部打开失败时仅写静态提示，不记录链接正文/计划内容。
- renderer 原有链接协议过滤继续保留。

## 验证

- `test/external-link-service.spec.ts` 覆盖 HTTP(S) 放行、危险协议拒绝、异步打开失败处理。
- 全量：`npm run typecheck`、`npm run test`（30 文件、261/261）、`npm run build` 通过。
