# 改动文档（2026-09-26 · 近期版本累计更新）

> 汇总上次改动文档（2026-09-09）之后至 v0.17.0 的近期版本，便于用户与协作智能体快速建立产品演进上下文。版本事实以 `docs/changelog/CHANGELOG.md` 和各版本发布说明为准。

## 本次发布：v0.17.0 公测版 Beta 6

### 任务列表三态

- 任务状态按「未开始 → 进行中 → 已完成 → 进行中」循环，保留可回退的三态模型。
- 修正任务状态选择器的点击反馈，让一次点击立即生效。

### 完全离线 PlantUML

- 随 Trace 安装包提供 PlantUML 与精简 Java 运行时；用户无需预装系统 Java、独立部署服务或在首次使用时联网。
- 应用窗口优先启动，PlantUML 服务随后在后台初始化。
- 设置中提供本地、自定义服务、关闭三种模式，以及端口、状态与重试入口；旧的非空服务地址迁移为自定义模式。
- 内置服务限制为 `127.0.0.1`，启用 SANDBOX 拒绝本地文件与 URL include，并关闭 PlantUML 统计。
- 修复 Muya 预加载器与正式 renderer loader 不共享实例的问题；在关闭服务、服务错误或切换端口时，不再使用过期地址发送注释源码。

### 兼容性与验证

- 计划 Markdown 格式和数据根目录不变；既有计划无需迁移。
- 自动验证：`npm run typecheck`、`npm run test`（39 个测试文件 / 388 项）和 `npm run build` 通过。
- Windows x64 安装包：200.82 MiB；SHA-256 `394DFFA219B9329B150D19D33DD0887FC67619551AE7E38093DF841E39B41699`。与 v0.15.1 相比减少 56.13%；包内 runtime 与构建产物一致，随包 Java/SANDBOX smoke 通过。
- 安装包未数字签名；Windows 可能显示未知发布者提示。尚未手动安装并交互启动 Electron GUI。
- GitHub/Gitee Release 结果发布后回填到 `builds/release_history.json`。

## 横向修复与架构收敛

- 计划树增删改移尽量局部刷新，维持展开状态并减少整树重载。
- 注释 Markdown 编辑与阅读态共享一致的图表状态；链接导航受限为安全的 HTTP(S) 目标。
- 统一按钮语义、删除确认与短时撤销；亮暗主题依赖语义 token，减少硬编码样式。
- 主进程负责本地文件、服务生命周期与 IPC；Renderer 通过受控 IPC 访问，避免直接操作文件系统。
- 搜索、日记、回忆和任务状态围绕“回到计划来源”组织，计划格式保持稳定。
