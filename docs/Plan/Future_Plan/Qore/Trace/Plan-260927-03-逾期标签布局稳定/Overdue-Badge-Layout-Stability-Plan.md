## 目标与范围

用户复现路径：任务详情里，已完成且计划日期已过的任务取消勾选后，“逾期”标签出现，卡片短暂跳动。核查任务列表的同款标签，保持卡片、标题和相邻字段在状态往返时位置稳定。保留逾期语义、主题 token 与减少动态效果设置。

代码边界由 Codex 在 `docs/HANDOFF-CURRENT.md` 登记：`src/renderer/src/components/cards/TaskDetailCard.tsx`、`TaskListCard.tsx`、`src/renderer/src/styles/cards.css`、`src/shared/task-state.ts`、`test/task-state.spec.ts`；真实浏览器回归脚本 `demo/frontend-foundation/overdue-layout-check.mjs` 及同目录 `README.md`。文档边界为本计划 Markdown/JSON、`docs/Plan/README.md`、当前 issue 和 HANDOFF。不修改用户数据、计划格式、IPC 或其他卡片行为。

## 验收标准

1. 取消已完成的逾期任务时，逾期提示正确出现；再次完成时正确隐藏。
2. 状态切换前、动画中和动画后，卡片外框以及标题/任务名布局位置稳定；任务详情与任务列表一致。
3. 不改变非逾期任务外观，不引入水平溢出或可访问性回退；减少动态效果下直接显示最终状态。
4. 自动检查和浏览器实测结果、尚未覆盖的场景均如实写入共享文档。
