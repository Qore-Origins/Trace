# Future_Plan-20260825-桌面端计划管理软件

##### 所属组织：叩心（Qore，即Qore Origins，具体内容见[Qore Origins](docs/OrganizationAndUser.pdf)）

## 目的
实现一个桌面端*计划管理软件*，用于管理用户的计划和任务。
用户可以在软件中创建、编辑、删除和查看计划和任务。
痛点来自于`计划排版乱`、`集成管理差`、`任务管理差`、`溯源、查询困难`、`计划编辑难`
因有痛点所以需要实现一个桌面端计划管理软件。

## 功能（大致）
<!-- - 1. 用户登录注册
- 2. 计划管理
- 3. 任务管理
- 4. 溯源查询
- 5. 系统设置 -->
- **存储模块**
文件夹存储计划，可嵌套、拖拽。

- **页面渲染模块**
最初是想直接渲染markdown但是编辑太难了，所以决定使用自定义的渲染模块。为常用的“计划单片组件”（单选计划、多选计划、任务列表、任务详情、注释）设计自定义的渲染。
