动效分解

D1行槽开合：每行 grid-template-rows: 0fr↔1fr 槽位错峰开合，下方内容平滑推走/合拢，零布局跳动
D2发牌入场：卡牌从父行方向（上·左）抽出，--i 错峰 + spring 回弹落位
D3收牌出场：末张先走、波次向上汇聚进父行，ease-in 加速吸入，槽位 zipper 合拢
D4折叠按钮：方框 +/- 号，点击整体旋转 180°，旋转途中竖杠消长完成变号 + 按压缩放反馈
D5父行脉冲：展开瞬间迹色一闪 + 图标 pop；收拢完成图标 squish
D6连接线生长：缩进竖线段锚顶 scaleY 随行画出——「迹」向下生长；收拢被槽位裁切自然回缩
D7持牌暗示：折叠文件夹 hover 露出两道卡牌边缘（这里有一摞牌）
D8节奏压缩：子项 >10 时交错间隔自动压缩，总时长封顶约 600ms
