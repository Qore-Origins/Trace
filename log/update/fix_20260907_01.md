# 修复计划树拖拽分区抽搐：计划行禁入内部 + 分区滞回防抖

**类型**：fix
**日期**：2026-09-07 22:35
**影响范围**：src/renderer/src/components/tree-utils.ts、PlanTreePanel.tsx、styles/workspace.css、test/tree-utils.spec.ts

## 变更描述

用户反馈（dev 实测）：①计划可被拖入另一计划内部——非预期，容器语义应归文件夹；②28px 行高切三分区后每区仅约 9px，指针在分区边界附近高频翻转意图，让位动画与入内高亮来回对切，视觉「抽搐」。

## 修改详情

- [tree-utils.ts]：`intentOf` 增加 `allowInto` 参数——计划行两分区（上半=前插/下半=后插，无入内部），文件夹/根行保持三分区；新增 `HYST_PX=4` 与 `applyHysteresis` 滞回防抖（同目标行内，指针须深入新分区 4px 才切换意图，分区边界形成死区）；`computeTreeMove` 对 plan+into 双保险返回 null；删除未引用的 TREE_INDENT
- [PlanTreePanel.tsx]：`treeCollision` 按目标行 kind 分区并接入滞回（`hystRef` 记录同行的上一意图）；`dropInto` 高亮改 onDragOver + onDragMove 双挂点派生（over null→null 不触发 onDragOver，纯 into 区间跳转时防高亮滞留）；新增 onDragStart/onDragCancel（含 dragActive 态，onDragEnd 同步复位）
- [workspace.css]：`.tree-scroll.is-dragging` 拖拽中抑制行 hover 底色与快捷按钮浮现（消除与让位/入内高亮叠加的闪烁噪声）
- [tree-utils.spec.ts]：intentOf 两分区用例、plan+into=null、applyHysteresis 边界 4 例（两分区中点/三分区上下边界/跨行无滞回），97 测试全绿

## 影响分析

- 行为变更：计划行不再接收入内部拖放（容器=文件夹）；计划嵌套仍可通过「新建子计划」入口（+ 按钮/右键菜单）实现，仅拖拽通道关闭——如需恢复拖拽嵌套，把 `treeCollision` 中 `allowInto` 对 plan 行改回 true 即可
- 滞回仅作用于同目标行内的意图切换；跨行切换不受影响（拖拽期间行矩形静态，无振荡源）
- 验证：typecheck + 97 测试 + build 全绿；建议用户 dev 路径——拖计划经过另一计划行（应只有让位、无入内高亮、边界不抖）→拖到文件夹行中部（入内高亮稳定）→在分区边界附近缓慢移动指针（意图切换有一次 4px 缓冲、不再高频对切）
