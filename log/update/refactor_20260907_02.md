# 计划树拖拽改用 @dnd-kit（同款 AI Resource Hub，antd Tree 退役）

**类型**：refactor
**日期**：2026-09-07 21:15
**影响范围**：src/renderer/src/components/PlanTreePanel.tsx、tree-utils.ts、styles/workspace.css、test/tree-utils.spec.ts

## 变更描述

应用户要求，计划树从 antd Tree 内置拖拽（插入线/目标高亮）改为与 AI Resource Hub 及组件卡一致的 @dnd-kit 体验：手柄拖拽、其余行实时让位动画、被拖行浮起（迹色描边+投影+置顶）。antd Tree 组件整体退役，改为自渲染扁平树。

## 修改详情

- [tree-utils.ts]：`buildTreeData`/`computeDrop`（antd 专用）删除；新增 `flattenTree`（childrenMap/loaded/expandedKeys → 可见扁平行 DFS，箭头数据驱动语义保持）、`intentOf`（三分区：上/下 1/3=前/后插，中 1/3=入内部）、`computeTreeMove`（意图 → movePlan 参数；**修正旧 computeDrop 的 0/1 简化为精确索引换算**，兄弟列表先剔除源——对齐主进程 removeOrderEntry 先于 insertOrderEntry 的语义）
- [PlanTreePanel.tsx]：antd Tree → 自渲染。RowContent（根/子行共享：缩进连接线+手柄+箭头+标题+快捷操作）、SortableTreeRow（useSortable）、RootTreeRow（useDroppable，仅接收「移到顶层末尾」）。自定义 `treeCollision` 碰撞检测：指针 y 命中行 → 三分区定意图；「入内部」不返回 over（无让位——避免「插到这里」误导），改由 dropInto 迹色高亮目标行；键盘传感器退化 closestCenter。懒加载保持（展开未加载层 → loadChildren，箭头转 LoadingOutlined）
- [workspace.css]：新增 `.tree-row`（hover/dragging 浮起/drop-into 高亮）、`.tree-guides/.guide`（每级 18px 竖线，迹的骨架）、`.tree-switcher`（含 loading/占位态）；`.tree-quick` hover 选择器从 `.ant-tree-node-content-wrapper` 迁到 `.tree-row`；删除 antd Tree 覆盖死代码
- [tree-utils.spec.ts]：U1 行为锚点迁移 flattenTree（空文件夹新建后箭头出现等 5 例）+ 新增 intentOf/computeTreeMove 7 例（同父剔除源换算、根只接收入内部、跨层保守末尾等），91 测试全绿

## 影响分析

- 存储链路零改动（仍走 movePlan IPC → children_order 精确索引持久化）；顺带修复既有缺陷：旧 computeDrop 前/后插硬编码 0/1（实际语义=插到父列表最前/第二位），现按目标真实索引换算
- 渲染 bundle 减约 160KB（antd Tree 移出主链路）
- 已知取舍（如实说明）：antd Tree 自带的行为中，虚拟滚动（本项目未用）与键盘上下键导航未复刻；键盘拖拽退化为「插入目标后」（PointerSensor 为主路径）；树行 hover 快捷按钮/菜单/懒加载/展开收起/选中全保留
- 建议用户验证路径：展开根→手柄拖计划到另一计划上/中/下三区（让位/高亮/让位）→拖入文件夹（高亮后松手，自动展开）→拖到根行（=顶层末尾）→重启确认顺序持久化
