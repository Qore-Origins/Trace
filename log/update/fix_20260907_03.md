# 树拖拽弹回根治：改 DragOverlay 模式（源行无 transform）

**类型**：fix
**日期**：2026-09-07 23:58
**影响范围**：src/renderer/src/components/PlanTreePanel.tsx、styles/workspace.css

## 变更描述

用户反馈（dev 实测）：乐观更新提交后「松手弹回原位」依旧存在。代码走查 + 对比 AI Resource Hub 参考实现确认：乐观路径逻辑正确（105 测试覆盖），但**无 DragOverlay 模式在结构上存在弹回窗口**——拖拽中被拖行靠 transform 跟随指针，松手时 dnd-kit 将 transform 复位并动画回其 DOM 槽位；该复位动画与 React 乐观换位的重排在同帧竞争，任何提交错位即呈现「弹回原位」。参考项目（无 DragOverlay、Tauri IPC 几十 ms）因时序窗口极小而未被感知，本项目 Electron IPC + 双层刷新 50-300ms 将窗口放大。

## 修改详情

- [PlanTreePanel.tsx]：接入 DragOverlay——`activeNode` 态（onDragStart 解析源行，clearDragState 复位）；`SortableTreeRow` 拖拽中 transform/transition 置 undefined（源行原地 `.dragging-src` 半透明，不再跟指针）；浮层渲染行影（图标+名称，迹色描边+投影）；`dropAnimation={null}`（松手浮层瞬间消失，落位完全交给乐观换位）
- [workspace.css]：`.tree-row.dragging-src { opacity: .45 }`；`.tree-row.overlay` 浮层样式（z-100、纸底、迹色环、投影、名称省略）；删除旧 `.tree-row.dragging`

## 影响分析

- 弹回原位在结构上不可能再发生：源行拖拽期间无 transform → 松手无复位动画；浮层消失与乐观换位同帧呈现
- 视觉变化：拖拽中源行原地半透明（而非跟指针浮起），行影跟指针浮动；兄弟行让位动画不变
- 另一可疑因素如实记录：本项目 HMR 曾静默失效（2026-09-06 用户报障），若用户测试窗口未加载 9b82117（乐观更新），所见为旧代码——已提醒完全重启 dev 复测
- 验证：typecheck + 105 测试 + build 全绿（纯逻辑未动，无新增用例）；dev 复验路径——顶层拖 A 到 C 后松手（行影消失、A 立即落位新槽）→ 拖入文件夹（高亮→行影消失→出现在文件夹内并展开）→ Esc 取消（行影消失、顺序不变）→ 重启确认持久化
