# 折叠按钮动效定稿——方框 +/- 旋转变号（demo 迭代）

**类型**：feature
**日期**：2026-09-08 11:20
**影响范围**：docs/prototype/tree-animation-demo.html

## 变更描述

用户定稿折叠按钮形态：弃用单箭头，改用「方框中间 +/- 号」样式——点击后方框整体旋转，旋转过程中竖杠消长完成 + 与 − 的变换（+ = 可展开，− = 可收拢）。在 demo 中替换 D4 实现并同步全部说明文案。

## 修改详情

- [tree-animation-demo.html]：
  - D4 重写：.pm-box（12px 描边方框，旋转载体）内嵌 .pm-sign 双杠（横杠常驻 + 竖杠 scaleY 消长）；.open 态 = 方框 rotate(180°) + 竖杠 scaleY(0) → 显示 −；旋转 300ms spring，竖杠 130ms linear 延迟 70ms——变号发生在旋转途中
  - transform 分层：旋转在 .pm-box、按压缩放 scale(.78) 在 .tree-switcher，互不覆盖
  - 图标常量 chevron → toggle（DOM 结构替换），说明文案/时间轴标签/交互约定同步更新

## 影响分析

- 纯 demo 迭代，正式组件未动；180° 旋转终态与始态视觉对称（+/− 均为旋转对称图形），状态切换无跳变
- 移植时同样分层：按钮按压反馈与方框旋转分离，CSS 可全量复用

## 相关问题

用户反馈（2026-09-08）：折叠按钮用方框 +/- 号，点击旋转，旋转过程中进行 -/+ 变换
