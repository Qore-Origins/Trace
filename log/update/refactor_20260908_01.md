# 计划树拖拽语义简化——裁撤排序，仅保留移入/移出文件夹

**类型**：refactor
**日期**：2026-09-08 01:04
**影响范围**：src/renderer/src/components/PlanTreePanel.tsx、src/renderer/src/components/tree-utils.ts、src/renderer/src/styles/workspace.css、test/tree-utils.spec.ts

## 变更描述

用户定稿：计划树拖拽不需要顺序调整，只需移出/移入文件夹。前一版（bf1020c..336aee2）的三分区排序落点（前插/后插/入内 + 滞回防抖 + 精确索引换算）整体退役，改为「拖到文件夹行=移入、拖到「计划库」根行=移到顶层」的纯容器落点；保留 @dnd-kit 浮起跟随动画（与组件卡同款手感）与松手乐观落位（optimisticMove 链路不变）。

## 修改详情

- [PlanTreePanel.tsx]：SortableContext/useSortable 退役 → useDraggable（手柄发起，计划/文件夹行可拖）+ useDroppable（文件夹行与根行为唯一落点，计划行不接收放置）；碰撞检测改为 pointerWithin（剔除被拖项自身，防文件夹拖拽时自身命中）；无效目标（自身/子孙/现父）不高亮、落点静默忽略（store 内 guard 兜底提示）；移入成功后目标文件夹自动展开
- [tree-utils.ts]：intentOf / applyHysteresis / computeTreeMove（三分区排序换算）随语义退役删除；flattenTree / kindOf / optimisticMove 保留
- [workspace.css]：.tree-row.dragging 补 scale 1.02（对齐 .card.dragging 浮起手感）；拖拽中 hover 抑制注释措辞更新
- [test/tree-utils.spec.ts]：三分区/滞回/索引换算测试随实现删除；flattenTree / kindOf / optimisticMove 测试保留

## 影响分析

- 树内不再支持拖拽排序（顶层/计划子级顺序不可通过拖拽调整）——按用户定稿移除；children_order 数据层与自愈逻辑（336aee2）不动，顶层顺序载体仍由 create/move 维护
- 文件夹内本就按名称排序（无顺序载体），移入/移出语义与数据层天然一致，乐观位与权威刷新位不会二次跳位
- 松手即落位、失败回滚的乐观更新链路保持；无效落点由 dnd-kit transform 复位动画弹回原位（纯视觉，无数据闪烁）
