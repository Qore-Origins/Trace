# 计划树散开/收拢动效设计方案与交互 Demo

**类型**：feature
**日期**：2026-09-08 11:02
**影响范围**：docs/prototype/tree-animation-demo.html（新增，零代码侵入）

## 变更描述

布局定稿后进入动效阶段。以用户提出的「卡牌摞」隐喻为基础（展开自上至下发牌、收拢相反），产出 D1–D8 动效设计定稿并制作单文件交互 Demo：复刻应用视觉 token 与树面板结构，内置实时调参控制台，用于在移植到正式组件前锁定节奏与手感参数。

## 修改详情

- [tree-animation-demo.html]：新增独立原型（浏览器直接打开，无构建依赖）
  - D1 行槽开合：每行 grid-template-rows 0fr↔1fr 错峰开合，零布局跳动
  - D2 发牌入场：卡牌从父行方向（上·左）抽出，错峰 + spring 回弹落位
  - D3 收牌出场：末张先走、波次向上汇聚，ease-in 加速吸入，槽位 zipper 合拢
  - D4 折叠箭头：单箭头 90° 弹簧旋转 + 按压缩放反馈
  - D5 父行脉冲：展开迹色一闪 + 图标 pop；收拢图标 squish
  - D6 连接线生长：缩进竖线段锚顶 scaleY 随行画出；收拢被槽位裁切自然回缩
  - D7 持牌暗示：折叠文件夹 hover 露出两道卡牌边缘
  - D8 节奏压缩：子项 >10 时间隔自动压缩，总时长封顶约 600ms
  - 工程：@starting-style 挂载即过渡（入场零 JS）；收拢延迟卸载 + 中途再点可取消（settled 类钉住防止动画重播）；prefers-reduced-motion 全禁用
  - 控制台：stagger/发牌/收牌/槽位时长滑块、回弹与连线开关、发牌顺序切换（首张/末张先发）、级联全开全收

## 影响分析

- 零代码侵入：正式组件未动，验证通过后再移植（递归 TreeGroup + useTreeAnim 包裹 setExpanded，CSS 全量复用）
- demo 数据含嵌套子树与 12 子项大文件夹，覆盖嵌套收拢与节奏压缩两条边界
