# 组件卡拖拽排序

**类型**：feature
**日期**：2026-09-07 18:30
**影响范围**：src/renderer/src/components/cards.tsx、src/renderer/src/styles/workspace.css

## 变更描述

计划内容区的组件卡支持拖拽排序（对齐 2026-09-06 15:58 用户需求「计划中的组件也能像文件树那样拖动」，该需求当时因限额中断未实现）。采用原生 HTML5 拖拽 + 专用手柄，零新增依赖。

## 修改详情

- [cards.tsx]：新增 `CardDragCtx` 上下文——`ComponentRenderer` 持有拖拽状态与索引换算逻辑，`CardShell` 消费上下文只转发事件（组件卡保持哑渲染）。手柄（HolderOutlined）发起拖拽并 `setDragImage` 整卡影像；卡身按上/下半区判定插入位（`dragover`/`dragleave` 含子元素防抖）；`drop` 时按拖拽方向换算目标索引后复用既有 `moveComponent`（先移除后插入语义，向下拖需 t/t+1 换算，已全路径验证）
- [workspace.css]：`.card .kind` 改 flex 布局放手柄；新增 `.drag-handle`（grab 光标、悬停变迹色）、`.card.dragging`（半透明）、`.card.drop-above::before` / `.drop-below::after`（迹色插入线，落在卡片 12px 间隙中央）

## 影响分析

- 仅渲染层，不动存储契约/IPC；排序走既有 `moveComponent` → 防抖保存 + CAS 链路，持久化行为不变
- 手柄式拖拽避免与卡内输入框文本选择冲突；上/下移按钮保留（键盘/微调场景）
- 验证：typecheck + 83 测试 + 构建全绿；建议用户路径——打开含 ≥3 组件的计划 → 按住卡片左上手柄拖动 → 观察插入线 → 松手确认顺序 → 状态栏"已保存" → 重启确认持久化
