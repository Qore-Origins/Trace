# Demo 动效降噪（D5 移除）+ 折叠按钮间歇性点击失效根治（三处竞态）

**类型**：fix
**日期**：2026-09-08 13:05
**影响范围**：docs/prototype/tree-animation-demo.html

## 变更描述

用户实测两现象：①展开后文件夹行出现类似「刷新」的动画；②折叠按钮间歇性点击失效。确认①为 D5 父行脉冲（整行闪迹色+图标 pop，读感为刷新，噪声）→ 移除；②与①无关，为三处竞态叠加：取消收拢时整组卡牌重播发牌（settled 钉住在早前并行编辑中被覆盖丢失）、级联按钮定时器晚到改写手动操作结果、祖先收拢途中展开子孙导致新组挂进「将死」子树造成状态与 DOM 脱钩。

## 修改详情

- [tree-animation-demo.html]：
  - D5 整体移除：CSS（parent-pulse/icon-pop/icon-squish）、JS（expand/startCollapse 的 flash 调用、flash 辅助函数）、说明面板 D5 条目改为移除标注
  - 竞态1（取消重播）：cancelCollapse 摘除 closing 时补挂 settled 钉住（.slot.settled 规则此前已在 CSS，JS 侧在并行编辑事故中丢失）——取消收拢现为平滑原路弹回，不再重播发牌
  - 竞态2（级联晚到）：cascadeSeq 代际计数——任何手动 toggle 或新级联使旧级联的全部待发定时器作废；「点了全部收拢又手动展开，稍后旧定时器把它收回去」不再发生
  - 竞态3（挂进将死子树）：expand 增加 ancestorClosing 守卫（任一祖先处于收拢途中则拒绝展开）+ expanded.add 移至挂载点确认之后（早退不遗留「已展开无组」假状态）；startCollapse 增加 group.isConnected 检查（脱钩组清理后下次点击自愈）
  - 附带补回并行编辑事故中丢失的根行守卫（startCollapse 不给根行加 has-deck 牌边暗示）

## 影响分析

- 「刷新感」消除：展开反馈仅剩方框变号 + 发牌动画本身
- 间歇性失效三源全堵：取消路径平滑、级联不回写、状态与 DOM 不脱钩；状态机所有早退路径均不残留假状态
- 教训沉淀：同文件多 Edit 并行调用在本工具链下会相互覆盖（本项目已发生 4 次），此后一律串行编辑
