# 组件卡拖拽改用 @dnd-kit（同款 AI Resource Hub）

**类型**：refactor
**日期**：2026-09-07 20:50
**影响范围**：src/renderer/src/components/cards.tsx、src/renderer/src/styles/workspace.css、package.json、package-lock.json

## 变更描述

应用户要求，将组件卡拖拽排序从原生 HTML5（插入线静态指示）改为与「AI Resource Hub」项目同款的 @dnd-kit 方案：拖动时其余卡实时让位并带过渡动画，被拖卡放大投影置顶——手感与插入线方案完全不同。

## 修改详情

- [package.json]：新增依赖 @dnd-kit/core@^6.3.1、@dnd-kit/sortable@^10.0.0、@dnd-kit/utilities@^3.2.2（与 AI Resource Hub 锁定版本一致；经 npmmirror 直连安装，临时 userconfig 绕过本机 7890 代理未启动问题）
- [cards.tsx]：删除 CardDragCtx 上下文与全部 HTML5 拖拽事件；CardShell 改用 useSortable（setNodeRef + transform/transition 内联，手柄挂 attributes/listeners）；ComponentRenderer 包 DndContext（PointerSensor distance 8 防误触 + KeyboardSensor 无障碍 + closestCenter 碰撞检测）+ SortableContext（verticalListSortingStrategy）；onDragEnd 复用 moveComponent（先移除后插入语义 = arrayMove 等价）
- [workspace.css]：删除插入线样式（.drop-above/.drop-below）；.card.dragging 改为浮起态（scale 1.02 + 迹色描边 ring + 大投影 + z-index 10，ring 用 box-shadow 避免布局跳动；scale 用独立 CSS 属性与 dnd-kit 内联 transform 正交合成）

## 影响分析

- 仅渲染层交互升级，存储/IPC/持久化链路不变（仍走 moveComponent → 防抖保存 + CAS）
- 渲染 bundle 增大约 114KB（dnd-kit 三件套），桌面端可接受
- 参考实现：D:\Code\Project\AI Resource Hub\src\hooks\useDragSort.ts 与 ProviderList.tsx（SortableProviderCard 包装模式）；本项目因卡型统一走 CardShell，useSortable 直接内聚在 CardShell，无需包装层
- 验证：typecheck + 83 测试 + build 全绿；建议用户路径——抓手拖动组件卡 → 观察其余卡实时让位动画 → 被拖卡浮起带迹色描边 → 松手顺序落定 → 重启确认持久化
